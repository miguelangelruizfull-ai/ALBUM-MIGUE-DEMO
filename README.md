# ALBUM-MIGUE-DEMO

Demo independiente de un álbum web cronológico.

## Objetivo

Mostrar una selección curada de recuerdos en una interfaz simple, responsive y compartible, sin depender de otros repositorios ni modificar proyectos anteriores.

## Estado

- Demo paralelo.
- Contenido seleccionado previamente.
- 2025 permanece fuera de la publicación hasta una revisión posterior.
- Las imágenes publicadas se copian con nombres neutros y se limpian de metadatos EXIF durante la preparación.
- El sitio incluye una opción para compartir y una guía para crear una versión propia.

## Publicación

Cuando el repositorio esté listo para compartirse:

1. Cambiar la visibilidad del repositorio a **Public**.
2. En GitHub: `Settings → Pages`.
3. En `Build and deployment`, elegir `Deploy from a branch`.
4. Seleccionar `main` y `/ (root)`.
5. Guardar y esperar a que GitHub Pages publique el sitio.

URL esperada:

`https://miguelangelruizfull-ai.github.io/ALBUM-MIGUE-DEMO/`

## Privacidad

Un repositorio o sitio público **no es “solo para quien tenga el enlace”**. Cualquier persona que obtenga la URL puede abrirlo y el repositorio público puede ser descubierto. Este demo incluye `noindex` para pedir a buscadores que no lo indexen, pero eso no sustituye controles de acceso.

## Reutilización

La estructura puede duplicarse para crear otro álbum reemplazando el contenido de `media/`.
